context
자율 AI 에이전트들이 한 프로젝트의 개발 전 과정을 함께 수행하도록 만든 틀입니다. 오케스트레이터 1기와 도메인 담당 8기가 서로를 무조건 믿지 않는 동료로 협업합니다. 핵심은 LLM 호출이 아니라, 에이전트를 어떻게 깨우고 인증하고 기억시킬지를 설계하는 일입니다.
A framework where autonomous agents carry a project's whole development cycle together — one orchestrator and eight domain agents working as mutually untrusting peers. The work is not calling an LLM; it is designing how agents wake, authenticate, communicate and remember.
approach — 7 patterns
위협모델 기반의 문서화된 설계 결정 34건 위에 설계한 핵심 7 패턴:
7 core patterns, built on 34 documented design decisions (threat-model-based):
  • A. 기본은 «거부» — 막아 두고 필요한 것만 기한을 정해 엽니다. 거부한 기록도 남깁니다.
  • B. 권한은 교집합까지만 — 거쳐 온 모든 단계가 함께 허용한 만큼만 갖습니다.
  • C. 말할 권리 ≠ 실행할 권리 — 신원은 서버가 확정하고, 실행 여부도 서버가 정합니다.
  • A. Deny by default — Permissions stay shut; each grant is explicit and expires.
